Why these drills

The four traps behind most mistakes.

Assembly order is not field order.
add rd, rs, rt becomes opcode rs rt rd shamt funct.
Decimal still needs conversion.
1001 decimal is not the same thing as the bit pattern 1001.
For LW, parentheses matter.
lw rt, offset(rs): the register in parentheses is the base rs.
Expressions can require a sequence.
(a+b)-c means ADD first, then SUB using the previous result.

Exam-safe workflow

Six moves, every time.

1
Identify the instruction.ADD/SUB → R. ADDI/LW → I. J → J.
2
Write the field skeleton.Do this before converting any number.
3
Map roles, not positions.For add $14,$28,$2: rd=$14, rs=$28, rt=$2.
4
Convert registers to 5 bits.$28 → 11100 · $2 → 00010 · $14 → 01110.
5
Convert the numeric field.I immediate = 16 bits. J address = 26 bits.
6
Insert opcode/funct and count 32.Field widths are your final error check.
